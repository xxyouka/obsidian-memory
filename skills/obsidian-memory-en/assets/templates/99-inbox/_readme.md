# 📥 Inbox

> Everything "capture now, sort later" goes here. Daily triage absorbs it into the right folder, then archives it to `_archive/YYYY-MM/`.

**Naming**: `YYYY-MM-DD-topic.md`

**Capture**: new preferences, project updates, external feedback, facts you don't know where to put yet.
**Never capture**: passwords, tokens, ID numbers, other people's private transcripts.
