# 🧠 {{OWNER}} 的记忆库 · 首页

> **这是什么**：{{OWNER}} 交给全部 AI 的**共享长期记忆**——偏好、角色、习惯、全部项目的长期信息都放这。
> **位置**：`{{VAULT}}`（Obsidian 库 + git 仓库）
> **原则**：**按区读取、增量更新、不重复记录**；只放「记忆级」摘要，原始资料不搬进来。

## 🗺️ 分区地图（按需读，别全库通读）

| 分区 | 内容 | 什么时候读 |
|---|---|---|
| `10-核心记忆/` | 偏好、角色、习惯、红线 | 任何涉及「怎么跟 {{OWNER}} 打交道」的任务 |
| `20-项目/` | 全部项目的定位、状态、技术栈、进展 | 任务涉及某个项目时：先读总览，再读单篇 |
| `30-每日记录/` | 每日沟通要点与进展 | 需要近期时间线时 |
| `40-周复盘/` | 每周沉淀总结 | 需要阶段性回顾时 |
| `50-沉淀库/` | 方法、经验、深度文章 | 需要方法或背景知识时 |
| `90-模板/` | 笔记模板 | 写新笔记时 |
| `99-收件箱/` | 未整理的新信息入口 | 每日整理时 |

## 📖 读取协议（省 token 版）

1. 先读本页，明确去哪找；
2. 进分区**先读 `_索引.md`**，再按需读单篇（L0 首页 → L1 索引 → L2 单篇）；
3. 外部大资料**默认不读**，任务确实需要时再精读，读完把结论回写本库。

## ⏰ 例程

- **每日整理**：把当天的新信息写进 `30-每日记录/`，同步 `20-项目/`
- **每周复盘**：产出 `40-周复盘/`，沉淀进 `50-沉淀库/`
- 完整规程：`01-读取与更新规程.md`
